# not6741.lol

Personal site for **not** — the best vibecoder ever.

Static HTML, no build step, no dependencies. What's in the repository is exactly
what GitHub Pages serves.

## Layout

| Path | What it is |
| --- | --- |
| `index.html` | The home page: hero, about, skills, projects, contact. |
| `notes/index.html` | The devlog. |
| `colophon/index.html` | How the site and its artwork are made. |
| `site.css` | The whole design system — tokens, nav, panels, prose. Shared by every page. |
| `site.js` | Shared behaviour: theme, nav, scroll reveal, toast, analytics. |
| `404.html` | Custom not-found page. |
| `feed.xml` | Atom feed for the notes. |
| `sitemap.xml`, `robots.txt` | Discovery. |
| `site.webmanifest`, `icon-*.png` | Installable-app metadata. |
| `*.png` | Project card art and the social preview, all generated by `swiss brand og`. |

## Editing

- **Projects** live in the `projects` array in the `<script>` block of `index.html`.
  Optional fields: `image`, `tags`, `status`, and `stat: { size, repo }` — the
  `repo` pulls a live download count from the GitHub API and fails silently.
- **Skills** and their snippets live in the `SKILLS` object just below it, with
  the highlighting rules in `LANGUAGES` above it.
- **The terminal** is `initTerminal()`. Commands are entries in the `COMMANDS`
  object; add a row to `HELP` so they show up in the command list.
- **Notes** are `<article>` blocks in `notes/index.html`. Add a matching
  `<entry>` to `feed.xml` and bump the `lastmod` in `sitemap.xml`.

## Theme

Every colour is a custom property at the top of `site.css`: one `:root` block for
dark, one `:root[data-theme="light"]` block for light. Each page applies the saved
theme from a small inline script in its `<head>`, which is the only reason there
is no flash of the wrong colours on load.

## Analytics

`site.js` has an `ANALYTICS_CODE` constant near the bottom. It is empty, so
nothing loads and no request is made. Sign up at
[GoatCounter](https://www.goatcounter.com/), put your site code in that string,
and page views start counting — cookieless, so it needs no consent banner.

## Hosting

Served by GitHub Pages with the custom domain `not6741.lol` (see `CNAME`).
Pushing to `main` redeploys automatically.
